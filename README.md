# 十三组 · 羽毛球循环赛记分台

13 组自由约赛，共 78 个唯一对阵。手机选择本组和对手后填写每局比分，可查看小组战绩、历史修改记录和自动更新的积分榜。

- 每局 11 分，10 平后领先 2 分获胜，15 分封顶（15:14 有效）。三局两胜，2:0 无需填写第三局。
- 胜 1 分、负 0 分；积分相同依次比较净胜局、净胜分，仍相同则并列。
- 同一对组别仅计一场，比分更正保留全部历史版本，并拒绝旧版本覆盖新记录。
- 第 7 组：廖浩轩 / 牟彬洁。
- 无需参赛者注册账号。提交前由双方核对比分，填报人姓名由参赛者自行选择。

## 部署

网页由 GitHub Pages 托管，发布源为 `main` 分支的 `/docs` 目录。
比赛数据存于腾讯 CloudBase 的 PostgreSQL 数据库，网页通过受限的匿名 RPC 接口访问；浏览器无权直接读写底层表。

当前腾讯云环境为六个月体验版，到期时间为 **2027-05-09 23:59:59（北京时间）**。2026-11-09 查询时自动续费和超额按量付费均为关闭。免费额度可能调整或耗尽，费用与可用状态以控制台为准。使用时定期导出 CSV 备份成绩。

## 本地修改

需要 Node.js 22.13 或以上版本：

```sh
npm ci
cp .env.example .env.local
# 填写 CloudBase 环境 ID 及仅有匿名权限的 Publishable Key
npm run build
```

将构建后的 `dist/` 文件复制到 `docs/` 后提交即可更新网页。Publishable Key 是专门用于前端公开访问的凭证；不要将服务端 API Key、Cloudflare/GitHub 令牌或账号密码放入前端或仓库。

数据库初始化脚本为 `database/setup.sql`。重新执行不会删除已有比赛记录。队伍成员变更时，同时修改前端 `src/lib/tournament.ts` 与云端 `badminton_private.teams` 对应组。

国内访问必须以实际手机网络测试为准，官方示例网页可访问不代表本站端到端流程已完成验证。
